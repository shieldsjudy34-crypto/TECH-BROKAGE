# PDSCOMM

Global AI software brokerage platform connecting government and enterprise buyers with qualified AI technology providers.

## Stack

- **Next.js 14** (App Router) + TypeScript
- **Tailwind CSS** — charcoal / stone / brass design system
- **Framer Motion** — restrained premium reveals
- **Lenis** — smooth inertial scrolling
- **Lucide React** — iconography

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Home — full brokerage narrative |
| `/buyers` | Institutional buyer pathways & intake |
| `/partners` | Technology partner onboarding |
| `/solutions` | Capability verticals & sourcing sandbox |
| `/trust` | Compliance, security, governance |
| `/engagements` | Anonymized case portfolio |
| `/about` | Ethos, footprint, leadership |
| `/insights` | Intelligence briefs & index |
| `/contact` | Secure dual-path intake & briefing |
